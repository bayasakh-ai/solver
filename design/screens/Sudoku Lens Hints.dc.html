How a hint unfolds
Three levels, one still frame
Tapping Hint freezes the camera and slides the still image up 80px, so the grid clears the sheet. Everything outside the reasoning is dimmed. Each level reveals more: where to look, why, and then the animated proof that ends with the digit written in.
Motion vocabulary
Ring · a digit that blocks, pulses in
Sweep · rules out a row or column
Cross · a cell that’s ruled out
Double ring + glow · the answer cell
Dashed lane · row or column
Solid frame · 3×3 box
4Wipe-in, ink blue · the answer
Reasoning strokes use the system’s amber, and answers use ink blue. The two stay distinct under every common color-vision deficiency, and each mark also has its own shape. At the start this puzzle has no hidden single for 7, so the storyboard uses 8 in the bottom-right box. All four hints are real steps, solved in order.
